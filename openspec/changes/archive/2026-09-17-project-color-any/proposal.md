# Цвет проекта — любой, а не из набора

## Why

Набор из шестнадцати цветов владелец отменил в день его появления: «мне нужен
колорпикер, а не 16 цветов». Заодно окно заводки проекта он попросил переделать
целиком — стена из кружков и значков занимала его полностью.

План и доказательства — [task-104](../../../../dock/tasks/task-104-вид-проекта-поповером-и-пипеткой.md),
основание — [Р-041](../../../../dock/decisions.md#r-041) (отменено этим изменением).

## What Changes

- цвет проекта — значение `#rrggbb`, а не имя из набора; дверь принимает только
  эту запись, остальное отклоняет;
- цвет значка на заливке считается по контрасту (белый или чёрный), а не задаётся;
- миграция 0028 переводит уже выбранные имена в те же значения;
- выбор вида — поповером у образца: поиск по значкам словом, восемь готовых
  цветов и пипетка.

## Capabilities

- `talk/projects` — изменённое требование «У проекта свой вид».

## Impact

- **данные:** значения в `project.color` переведены миграцией; схема не менялась
  (колонка `text` без `CHECK` с 0024);
- **протокол:** `POST/PATCH /v1/projects` — `color` теперь строка `#rrggbb`;
  прежние имена отклоняются с 422, старым вкладкам нужна перезагрузка;
- **проверки:** гейт контраста больше не проверяет цвета проектов (их выбирает
  человек); правило проверяют точечные тесты `inkOn` перебором куба RGB.
