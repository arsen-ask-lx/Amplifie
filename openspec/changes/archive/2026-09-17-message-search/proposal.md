# Поиск по сообщениям

## Why

Поиска по переписке не было: он пропал при перестройке экрана (Д-46).
Найти, где обсуждали договор, можно было только листая глазами, а переписка
копится — владелец ждёт миллионы сообщений за год на установку.

План, замеры и доказательства — [task-100](../../../../dock/tasks/task-100-поиск-по-сообщениям.md).

## What Changes

- таблица поиска — производная от сообщений, её держит в согласии триггер
  в базе на любом пути записи; миграция заполняет старые сообщения под замком;
- дверь `POST /v1/search/messages`: слова по форме и началу, права ленты,
  новые сверху, страницы по курсору;
- окно поиска по Ctrl+K: пауза и отмена прежнего запроса, строка с чатом
  и подсветкой, переход к найденному.

## Capabilities

- `talk/search` — новая: поиск по сообщениям.

## Impact

- **данные:** новая таблица `message_search`, два индекса, два триггера на `message`;
- **протокол:** новая дверь `POST /v1/search/messages`;
- **нагрузка:** замер шага 0 на 1 млн — худший случай 22 мс; запись с триггером
  в пределах шума прогонов (около −10% пропускной способности, +14% к 0.99);
- **интерфейс:** кнопка поиска в шапке и Ctrl+K.
