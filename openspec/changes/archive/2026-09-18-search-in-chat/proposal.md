# Поиск внутри одного чата

## Why

Поиск был один — по всем видимым чатам (Ctrl+K). Владелец 17.09: «как в тг,
оба» — лупа и Ctrl+F ищут в открытом чате со счётчиком «3 из 17», Ctrl+K
остаётся общим.

План, замеры и доказательства — [task-106](../../../../dock/tasks/task-106-поиск-внутри-чата.md).

## What Changes

- дверь `POST /v1/search/messages` принимает `conversationId` и отдаёт
  `total` — число попаданий с потолком 1000 (только для поиска в чате);
- индекс `(conversation_id, seq)` на таблице поиска: без него частое слово
  в маленьком чате читало 11 704 буфера вместо 24;
- полоса поиска в чате: поле, счётчик, стрелки, Escape;
- ход по попаданиям внутри загруженного окна ленты не перезагружает её.

## Capabilities

- `talk/search` — изменённое требование (поиск в одном чате и счётчик).

## Impact

- **данные:** новый индекс на `message_search` (миграция 0029), схема та же;
- **протокол:** необязательное поле запроса и необязательное поле ответа;
  старый клиент продолжает работать — поля необязательные;
- **цена:** страница поиска в чате 24–102 буфера, подсчёт «всего» 24–447
  (замер на 200 тыс. реплик); гейт `make cost` стережёт индекс.
