# Описание API и его арбитр

## Why

У бека 51 дверь и не было описания API: что двери обещают, никто не сверял с тем,
что они делают. Первый прогон Schemathesis нашёл 500 с текстом SQL наружу и 500 на
странном вводе (task-120, Р-049).

## What Changes

- описание API собирается из схем дверей и лежит в `backend/openapi.json`;
- неверный ввод — 422, а не 500; внутренняя ошибка — без текста ошибки;
- незнакомый метод на известном пути — 405 с `Allow`.

## Capabilities

- `api/contract` (новая)

## Impact

- бек: двери, договор `packages/contract`; фронт — только типы.
