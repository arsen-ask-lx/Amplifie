# «Переслать» ищет чат по названию

## Why

Окно «Переслать» брало весь список пространства одним ответом: на засеянной
базе 1,4 МБ и 5 241 строка ([Д-41](../../../../dock/debt.md#d-41)). Поля поиска
не было, а отказ загрузки молча проглатывался. Решение владельца от 16.09 —
«найди чат, а не отдай всё».

План и доказательства — [task-117](../../../../dock/tasks/task-117-переслать-ищет-чат.md).

## What Changes

- новая дверь поиска чата по названию: текст в теле, не в адресе, — как
  у поиска по сообщениям;
- окно «Переслать» с пустым полем показывает чаты, уже известные панели;
  набор ищет по всем видимым корневым чатам, включая свёрнутые папки;
- отказ поиска назван строкой с «Повторить»;
- дверь списка разговоров отдаёт не больше ста строк ([Д-15](../../../../dock/debt.md#d-15)).

## Capabilities

- `talk/search` — требования «Поиск чата по названию» и «Окно „Переслать“».

## Impact

- новая дверь `POST /v1/search/chats`, порог частоты поиска;
- `GET /v1/conversations` — первые сто; база не меняется.
