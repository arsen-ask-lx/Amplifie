Установка Amplifie на свой сервер. Нужны Docker и Docker Compose; Node не нужен.

```sh
# 1. Сверить, что файлы не повреждены и не подменены по дороге
sha256sum -c SHA256SUMS

# 2. Загрузить образы из архива — в сеть за ними установка не ходит
docker load -i amplifie-*-images.tar.gz

# 3. Родить настройки установки: пароль базы и ключ шифрования, порт 8080
docker run --rm -v "$PWD:/w" -w /w node:24-alpine node make-env.mjs box 8080

# 4. Поднять
docker compose up -d --pull never
```

Первый зарегистрированный человек заводит компанию, остальные входят по приглашению.
Версию установка называет сама: `curl http://localhost:8080/health`.

⚠️ Выпуск не подписан — ключа подписи ещё нет (Р-030). Контрольные суммы лежат
на этой же странице и защищают от повреждения, но не от подмены самой страницы.
