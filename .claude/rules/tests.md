# Тесты — сначала скилл `test-quality`

Правило подгружает движок, когда открыт тестовый файл (task-126). Перед тем как писать,
править или удалять тест, — загрузи скилл `test-quality`. Главное:

- назови поломку, которую тест ловит; ожидание — литерал, не результат проверяемого кода;
- никакого «не пусто» последней проверкой (`make weak-asserts`), никакого сна в браузере
  (`make lint`) — ждать признак;
- удаление теста — с названным дублем, разрешением владельца и строкой `удалён тест:`.
