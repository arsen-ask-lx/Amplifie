# Схема и миграции — сначала скилл `safe-migrations`

Правило подгружает движок, когда открыт файл схемы или миграции (task-126). Перед правкой —
загрузи скилл `safe-migrations` и следуй ему. Главное:

- все ожидающие миграции идут **одной транзакцией** — `CREATE INDEX CONCURRENTLY` невозможен;
- применённую миграцию не правим: ошибка — новая миграция;
- сгенерированный SQL читается глазами; перенос данных — порциями и не в мигратор.
