# Конвейер смотрит агент

> ⚠️ **Сейчас смотреть нечего: у репозитория нет удалённого.** `.github/workflows/ci.yml`
> написан и ни разу не запускался — первый `git push` будет и первым прогоном. До того всё
> ниже — инструкция впрок, а зелёным считается только локальный `make check`.

## Правило

Человек пушит — **дальше работа агента**. Не ждать скриншота ошибки, не спрашивать
«сообщите, если упадёт». Красный конвейер — это не сборка с предупреждением: следующие шаги
просто не наступают, и работа стоит молча.

Тот же класс тишины — когда прогона нет **вообще**: ветка не подходит под условие запуска,
файл рабочего процесса невалиден, лимиты исчерпаны. Отсутствие красного не означает зелёного.

> 📏 На соседнем проекте так простояло пятнадцать наборов правок с красной сборкой. Слова
> владельца: «я не должен говорить тебе о нём — ты должен сразу это делать после моего пуша».

## Команды

```
gh run list --limit 5                  # последние прогоны: статус, ветка, номер
gh run watch <id>                      # ждать окончания прогона
gh run view <id>                       # шаги и какой упал
gh run view <id> --log-failed          # лог только упавших шагов — с него и начинать
gh run rerun <id> --failed             # перезапустить только упавшее
```

Ловушки:

- `gh run list` без `--branch` показывает **все** ветки — легко принять чужой зелёный за свой;
- `--log` тянет весь лог целиком и топит контекст; нужен `--log-failed`;
- прогон появляется в списке не мгновенно после пуша — секунды задержки это норма,
  минута молчания — повод посмотреть, а запустился ли он вообще.

## Порядок разбора

1. Прогон вообще есть? Нет — разбираться с условием запуска, а не ждать.
2. `--log-failed`, читать **первую** ошибку, а не последнюю: дальше идут следствия.
3. Воспроизвести локально той же командой из `make`. Не воспроизводится локально — значит
   расходятся среды, и это отдельный дефект, а не «повезло».
4. Починить, прогнать `make check`, попросить человека запушить.
5. Три попытки не помогли — стоп и к человеку с описанием того, что пробовал.

## Как докладывать

Одной строкой: что упало, почему, что сделано. Не пересказом лога.

Пока не зелено — так и говорить «конвейер красный, чиню», а не «изменения отправлены».
