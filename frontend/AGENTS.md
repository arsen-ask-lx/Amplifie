# Правила frontend

Корневой AGENTS.md действует всегда. Ниже — дополнительные правила для интерфейса.

## Интерфейс

Полный стандарт вида — [`DESIGN.md`](../DESIGN.md) в корне: характер, роли
цветов, типографика, ритм, окна, три вида полей, движение, слова
и анти-паттерны. Ниже — то, что обязательно помнить, не открывая его.

- Ограничения задаются до генерации. Цвета берутся только из токенов в
  `frontend/src/styles.css`; сырой цвет в компоненте запрещён.
- На экран приходится один `h1`, одно главное действие и один смысловой акцент.
- Пространство показывает иерархию; рамка, номер и разделитель применяются только
  когда кодируют смысл. Декор без функции удаляется.
- Контраст текста не ниже 4.5:1, интерактивных границ — 3:1; строка текста короче
  примерно 80 знаков.
- Модальное окно закрывается Escape, кликом снаружи и понятной кнопкой внутри;
  внутреннее действие не меняет размер окна, ряд действий выровнен вправо.
- Текст называет предметы языком человека, кнопка сообщает результат действия,
  ошибка объясняет случившееся и следующий шаг, пустой экран приглашает к действию.
- Арбитр внешнего вида — снимок или живой прогон, сверенный с ограничениями,
  а не мнение модели, которая этот интерфейс создала.
