# dock/ci — разбор красного CI, которое хук ещё не знает

Сюда идёт файл разбора, когда `tools/agent/ci-red-audit.mjs` находит на коммите
падение CI, которого нет в `tools/ratchets/ci-known-red.txt`. Без него хук
`commit-msg` отклоняет коммит (task-126, п. 3 «Как делаем»).

Один файл на один прогон: `dock/ci/<databaseId>.md`, `databaseId` — как в
`gh run view <databaseId>`.

## Шаблон

```markdown
## Текст падения

Точный текст падения (сообщение assert, стек, вывод шага) — не пересказ.

## Класс

Одно слово: продукт · тест · окружение · инструмент.

## Причина

Одной фразой — что именно сломалось и почему.

## Что уже описано

Ссылка на Д-NN в `dock/debt.md`, спеку, решение или найденный код рядом —
или «ничего не нашлось» с тем, что искалось.
```

После файла: если падение решено считать признанным (не чинить сейчас) —
строка `ключ | Д-NN` уходит в `tools/ratchets/ci-known-red.txt`, а сам файл
разбора остаётся здесь как история. Если падение чинится — файл разбора
всё равно остаётся, просто новые прогоны его больше не требуют.
