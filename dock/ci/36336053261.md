## Текст падения

Ключи сторожа: `Schemathesis › Stateful tests › Resource is not available after creation`,
`Schemathesis › PATCH /v1/messages/{id} › API rejected schema-compliant request` — оба
внесены в храповик (Д-77, Д-89): фаззер выбивает их случайно, пока не починены.

1. `api-fuzz (stateful)`, случай `NB2VZC`: «Resource is not available after creation» —
   `POST /v1/conversations` создал чат, `PATCH /v1/conversations/{id}` с

   `404 {"error":"not_found"}`.
2. `api-fuzz (1/4)`, `PATCH /v1/messages/{id}`, случай `3GXJ0j`: «API rejected
   schema-compliant request» — тело `{"body": "\t", …}` получило
   `422 {"error":"validation_failed","fields":{"body":"сообщение пустое"}}`.

## Класс

продукт — описание API расходится с сервером; сам сервер ведёт себя верно.

## Причина

1. Ответ 404 про ссылку из тела (несуществующий проект) фаззер читает как пропажу самого
   чата. Сервер прав, что отказывает; спорно, каким кодом — это уже записано.
2. Схема тела разрешает любую непустую строку, а сервер обрезает пробелы и отвергает
   тело из одних пробельных знаков. Описание обещает то, чего сервер не принимает.
