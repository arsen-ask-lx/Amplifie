## 1. Зачем

Владелец выбрал первый вариант каталога: полукруглый 2px-контур с мягким свечением при фокусе.
Он возвращает понятную границу, но оставляет поле лёгким, потому что свечение не висит постоянно.

## 2. Что уже есть

- `KeyPanel.tsx`, `ModelScreen.tsx` — локально отключили постоянный контур в task-050.
- `input.tsx`, `select.tsx` — готовые единые поля с 2px-контуром и доступным фокусом.
- `field-boundary-variants.html` — выбран владельцем вариант №1.

## 3. Как делаем

Возвращаем этим полям готовый 2px-контур, увеличиваем радиус до полукруглого и добавляем один
локальный класс мягкого focus-свечения. Свечение — только на `:focus-visible`; постоянный стиль
не использует отдельной заливки или тени.

**Расхождения с решениями:** нет; используем существующие Input/Select и роли тем.

## 4. Шаги

1. Изменить красную UI-проверку с утопленного поля на 2px контур и focus-свечение.
   - файлы: `frontend/tests/ui/agents.spec.ts`.
   - проверка: текущая реализация даёт 0px границу.

   - проверка: обычное поле имеет контур, после Tab/фокуса получает тень.
3. Прогнать типы, линтер и UI-набор.

## 5. Признаки приёмки

- П-1: открыть «Агенты» → поля API имеют полукруглый 2px контур.
- П-2: поставить фокус клавиатурой → появляется мягкое тематическое свечение.
- П-3: уйти с поля → свечение исчезает, контур остаётся.
