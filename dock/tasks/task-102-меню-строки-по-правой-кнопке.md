## 1. Зачем

Замечание владельца 17.09: «3 точки вообще убрать… справа счётчик… правой
кнопкой мыши: закрепить, добавить в проект, удалить». Решение 17.09:
у проектов так же.

## 2. Что уже есть

Прочитано целиком: `ChannelRow.tsx`, `RowMenu.tsx`, `ProjectRow.tsx`,
`RoomList.tsx`, `shared/ui/context-menu.tsx`, сценарии `projects.spec.ts`
и `channels.spec.ts` в местах, где зовут меню.

- Меню по правой кнопке уже есть (`context-menu.tsx`, Radix): пункт,

## 3. Как делаем

1. **Одно меню на все чаты.** `ChannelRow`: строка целиком — область
   `ContextMenuTrigger`. Внутри тот же набор пунктов для чата в проекте
   и вне его. `ProjectChannelActions` и `LooseChannelMenu` уходят: две ветки
   по принадлежности заменяются одной (DRY — развилка была только из-за
   места для кнопок, которого теперь нет).
2. **Проект — то же правило.** `ProjectRow`: заголовок проекта —
   своя область меню (не вложенная: тело с чатами — снаружи неё, иначе
   правая кнопка по чату открыла бы меню проекта).
3. **`RowMenu.tsx` удаляется** — у него не остаётся ни одного потребителя
   (гейт мёртвого кода иначе покраснеет). Удаление файла — по отдельному
   слову владельца; одобрение этого плана им считаю.
4. **Число у края:** значки уже стоят `ml-auto` внутри кнопки строки —
   без кнопок справа они оказываются у края сами. У проекта скрытый плюс
   по-прежнему занимает место: число встаёт левее него, и это честно —
   плюс появляется там же при наведении, строка не дёргается.
5. **Комментарии-решения** в `ChannelRow` и `ProjectRow` переписываются
   на новое правило со ссылкой на отмену; запись в `dock/decisions.md`.
6. **Сценарии:** один помощник `rowAction(page, row, item)` в `fixtures.ts`
   (правая кнопка по строке → пункт) вместо дюжины щелчков по «Что сделать
   с каналом…». Сценарий «чат внутри проекта даёт pin и delete вместо трёх
   точек» заменяется новым — требование сменил владелец, это не ослабление
   арбитра.

**Отвергнуто:**
- оставить точки и добавить правую кнопку — два входа в одно меню,
  владелец просил точки убрать;
- своё меню поверх `onContextMenu` — готовое Radix-меню уже умеет клавиатуру,
  край экрана и подменю.

- **П-2 число у края:** у чата с непрочитанным правый край значка — в пределах
  отступа строки от её правого края (геометрия здесь — поведение: владелец

  спрашивает подтверждение.
- **П-4 проект и клавиатура:** правая кнопка по проекту — «Закрепить»,
  «Редактировать проект», «Убрать проект»; `Shift+F10` на строке в фокусе

**Числа до кода:** сервер не трогается — RED, USE и цена в запросах не меняются.
