# task-053-спокойные-поля-агента: нижняя линия вместо контура

Статус: на ревью 2026-09-11
Риск: низкий — только локальное оформление уже существующих полей
Заведено: 2026-09-11

## 1. Зачем

Владелец отверг выбранный ранее полный 2px-контур: цвет и свечение делают поле тяжёлым.
Нужно спокойное решение без эффекта, которое одинаково работает в темах.

## 2. Основание решения

Изучены рекомендации Carbon для текстовых полей: их продуктивный вариант использует
контекстную поверхность и нижнюю линию в покое, а фокус показывает контрастной 2px-линией.
Поле и его подпись остаются различимыми; декорация не заменяет состояние фокуса.

Источники:

- https://carbondesignsystem.com/components/text-input/style/
- https://carbondesignsystem.com/components/text-input/usage/

## 3. Как делаем

Только на экране «Агенты» заменяем полный контур и `field-reveal`:

- спокойная полукруглая поверхность `raised`;
- одна нижняя 1px-линия роли `line` в покое;
- при `focus-visible` нижняя линия становится 2px цветом `ink`;
- без box-shadow и без акцентного цвета.

Общий `Input` и `Select` не меняем: другим экранам не навязывается новый вид.

## 4. Шаги

1. Заменить красную UI-проверку прежнего полного контура на нижнюю линию и отсутствие тени.
2. Убрать класс свечения, ввести локальный класс спокойного поля, применить к ключу,
   спискам и строке моста.
3. Прогнать типы, линтер, карту и UI-набор на собранном фронтенде.

## 5. Признаки приёмки

- П-1: поля API и строки моста не имеют полной рамки или свечения.
- П-2: в покое видна только тонкая нижняя нейтральная линия.
- П-3: клавиатурный фокус даёт нижнюю 2px-линию цвета текста.

## 6. Арбитр

- тест: CSS-проверка нижней линии и отсутствия box-shadow после focus;
- живой прогон: `/agents` на светлой и тёмной теме.

## 7. Границы

- менять: локальный CSS, поля раздела «Агенты», UI-тест, план и карту;
- не менять: глобальные Input/Select, API, данные, остальные формы.
