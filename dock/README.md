## Что это за проект

Рабочее пространство, где **агенты присутствуют там, где люди договариваются**,
и превращают договорённости в задачи, не дожидаясь, пока кто-то откроет трекер.
Подробно и без техники — [01-что-строим.md](01-что-строим.md).

Ядро продукта — петля из пяти звеньев:

```
К1 агент слышит → К2 отличает договорённость от болтовни → К3 формулирует
→ К4 человек подтверждает → К5 задача уносит контекст
```

⚠️ Звенья последовательные: если каждое работает на 80%, петля работает на 33%.
Самое слабое обычно К2, и он **не решён ни у кого** из разобранных продуктов.

## ⚠️ Неприятное, что видно только сводно

**Часть решений принята кодом, а не решением.**

Я построил срез «вход» на Р-1 (участник одной сущностью), Р-2 (журнал), Р-3
(две привязки ответственности), Р-7 (ключ арендатора), Р-8, Р-9 — и **ни одно
из них не утверждено явно**. Они работают, они, по-моему, верные, но формально
их никто не принимал.

То же с В-1: развилка «форк paperclip / форк buzz / своё» в документах открыта,
а по факту **решена написанным кодом в пользу «своё»**.

Это ровно тот долг непонимания, о котором предупреждают ваши же материалы:
согласился на дизайн, которого не рассматривал. Лечится дёшево — пройти реестр
ниже и сказать «да» или «нет» по каждому. Пока не пройден, каждая строка кода
опирается на неподтверждённое.

### ⚖️ Открыты — ответить может только владелец

| | Вопрос | Что блокирует |
|---|---|---|
| **О-1** | **лимит токенов в минуту вашего тарифа** | сайзинг агентской части — вообще не считается |
| **О-2** | **сколько в месяц не жалко на модель** | может ли агент слушать; вся экономика Э2 |
| О-3 | продукт внутренний или публичный сервис для чужих компаний | многоарендность, RLS, лицензии |
| О-4 | первый живой пользователь: только вы или команда? сколько человек | половина волны 1 |
| О-5 | где сервер, какие мощности, есть ли домен | топология, выкат |
| О-6 | SLO: 99% (3.6 дня простоя) или 99.9% (8.8 часа) | резервирование = деньги |
| О-7 | RPO и RTO: сколько данных не жалко потерять, за сколько поднимаемся | бэкапы |
| О-8 | сколько лет храним журнал | партиционирование |
| О-9 | есть ли срок, к которому что-то должно работать | объём первого среза |
| **Р-11** | **первый срез: свой чат или сразу Telegram** | «прийти туда, где говорят» стоит в волне 1, опоры в ядре ноль |
| О-10 | порог доли выдуманного (я предлагал 5%) | кил-гейт Э0 |
| О-11 | канал: засевается миграцией или создаётся при регистрации | нужен ли экран создания канала в срезе |

### ⛔ Не спроектировано, и это главная дыра

| | Что | Почему это блокер |
|---|---|---|
| **А-1** | **арбитр К2** — чем докажем «не выдумал» и «контекст доехал» | по вашему же правилу проектируется **до** кода. Ни один из пяти разобранных продуктов такой проверки не имеет |
| А-2 | мера против «штамповки одобрений» | если человек принимает 100% предложений — это не «агент идеален», а «человек перестал читать» |
