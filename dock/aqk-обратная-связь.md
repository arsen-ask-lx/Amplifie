# AQK на Amplifie: что помогло, что сломано

Проект: TypeScript, Fastify + React, Biome вместо eslint, Windows 11 у владельца,
Linux в CI. Обновление 0.7.0 → 0.12.0 — [task-029](tasks/task-029-обновление-agent-quality-kit.md),
11.09.2026. Каждый пункт — с воспроизведением.

## Помогло

- **`doctor --run` под Windows работает (0.12.0).** Все 34 объявленных гейта
  прошли через Git Bash из PowerShell за 72 с. До этого под Windows мы держали
  свою обёртку `tools/checks/run-gates.mjs`, и она же брала WSL-запускатель
  вместо Git Bash — все shell-гейты падали ложно. Исправление в AQK делает
  нашу обёртку лишней.
- **Гейт `commit-explains-itself` поймал реальное.** Агент писал коммиты
  без разделов «Сделано:» / «Не уверен:» всю сессию; поймано только этим гейтом.
- **Счёт «правил под человеком»** (13 из 20 в AGENTS.md) — полезная и неудобная
  правда, которой больше нигде не видно.
- **`covers:`, `docs:`** — ровно те поля, которых не хватало: объявление,
  что `lint` уже держит записи каталога, стало машиночитаемым.
- **`probe` честно ходит по файлам с историей правок** — выбор мест для
  подсадки по «fixes in history» разумный.

## Сломано (дефекты)

1. **`covers:` проверяется кодами правил Ruff в любом проекте.**
   Заявка `covers: { lint: [no-print-in-prod, complexity-limit, swallowed-error] }`
   в TypeScript-проекте с Biome даёт «claim unverified: … linter config names
   rules T20 / C901, PLR0912, PLR0915 / BLE, TRY400, SIM105». Это коды Ruff;
   у Biome те же правила зовутся `noConsole`, `noExcessiveCognitiveComplexity`,
   `noEmptyBlockStatements` — и они в `biome.json` есть. Заявка не подтверждается
   никогда, хотя правило стоит.
   - воспроизвести: `biome.json` с этими тремя правилами + `covers:` как выше →
     `aqk doctor`.
2. **`probe` пишет в рабочее дерево, обещая обратное.** Вывод: «The working
   tree is not touched»; после прогона появляется неигнорируемый
   `.aqk/last-probe.md`. Либо `.aqk/` в `.gitignore` должен ставиться китом,
   либо фразу надо уточнить.
3. **`probe` засчитывает любое падение как «поймал».** Класс «colour comes from
   a theme token» у нас «caught by: lint», хотя Biome цвета не проверяет —
   для этого есть отдельный гейт `color-from-token`. Вероятно, подсаженный
   образец ломает формат файла, и падает форматтер, а не правило. Результат —
   ложная уверенность: «every applicable class is caught by something».
   Нужна сверка, что упавший гейт упал на подсаженном месте и по тому классу.
4. **`vitals`: «could not reach the registry — freshness unknown»** при рабочем
   `npm view agent-quality-kit version` на той же машине.

## Вводит в заблуждение

5. **Советы «Start with these three» не видят существующих проверок Biome.**
   0.12 обещает находить существующие проверки в `package.json`, `Makefile`
   и т.п., но `biome.json` не читает — и советует поставить через eslint то,
   что уже держит Biome. Для проекта без eslint это совет завести второй
   линтер.
6. **`api-contract-has-arbiter` — «no API specification in sight».**
   Контракт у нас есть — zod-схемы запросов и ответов в общем пакете,
   проверяемые сервером (Р-034), — но кит узнаёт только файлы
   openapi/swagger/asyncapi по имени. Типизированный контракт в коде
   (zod + type provider, tRPC, ts-rest) остаётся невидимым.
7. **`doctor --run` без выключенного `probe` может внезапно стать долгим.**
   С 0.10 он сам запускает `probe` раз в 100 коммитов (у нас ~110 с).
   В CI это непредсказуемый скачок длительности; стоит печатать заранее,
   что сейчас будет probe и сколько он обычно идёт.
8. **Нет способа объявить гейт, которому нужна живая система.** Наш гейт
   цены горячего запроса меряет план на засеянной базе. Объявленный обычным,
   он валит `doctor --run` там, где стенда нет (быстрая задача CI, `make check`),
   отказом соединения, а не находкой; убранный из манифеста — становится
   невидим для `promise-has-gate`, и правило в AGENTS.md «ведёт в никуда».
   Обошлись `advisory:`, но это компромисс: гейт блокирует только отдельным
   шагом CI со стендом. Нужен признак вроде `needs: stack` — гейт пропускается
   с явным «не мерил: нет стенда», а не краснеет и не молчит.
9. **`aqk help`: у `vitals` вместо описания — `undefined`.**

## Уже доехало до AQK

- Отчёт «гейты под Windows берут bash из WSL» процитирован в исходнике 0.12
  (`tool/lib/run.mjs`, выбор Git Bash) — исправление подтверждено у нас:
  34 гейта из PowerShell.
