# Р-036. Как мост попадает к человеку

| | |
|---|---|
| **Статус** | ✅ принято 2026-09-11 (владелец: «нужно придумать что-то для людей, далёких от программирования»; на программу как цель и строку первой — «ок давай тогда так и сделаем») |
| **Почему сейчас** | мост запускает код на машине человека и держит его подписку — признак «цена ошибки высока» из AGENTS.md |
| **Связано** | [Р-012 подключение моделей](012-подключение-моделей.md) |

## Что сломано сейчас

Сайт выдаёт строку `npm run bridge -- --code <код>`. Это скрипт нашего репозитория:
он собирает мост из исходников и работает **только из папки с кодом**. Владелец
проверил 11.09 — cmd, PowerShell и WSL из домашней папки отвечают «нет package.json»;
на Mac будет то же. Вторая ошибка той же строки: в ней нет адреса сервера, и мост
идёт на `localhost:8477` — у коллеги на другой машине это пустота. Поставить мост
человеку сейчас нельзя никак: его нет ни в npm, ни файлом на сайте.

## Решение

Три пути, от простого для нас к простому для человека. Цель — третий; первый
чинится сразу, потому что он же — запасной путь навсегда.

| | Путь | Что делает человек | Кому |
|---|---|---|---|
| А | **строка** — `npx` берёт мост одним файлом с нашего же сервера, адрес подставляет сайт | копирует строку в терминал | программистам; WSL и Linux |
| Б | ~~файл двойным щелчком~~ — отклонён ниже | — | — |
| В | **программа «Amplifie Мост»** | скачал, поставил, нажал «Разрешить» на сайте | всем |

Как устроена программа:

- **внутри наш же мост**, тот же код: программа на Electron, у которого Node
  встроен, — мост работает в ней как есть, без второго языка;
- **подключение без кода**: программа открывает сайт, там «Подключить этот
  компьютер?» → «Да»; окно на сайте само становится зелёным — живое у нас уже
  есть (Р-006);
- **проверяет Claude сама** и говорит словами: «не установлен» → «Установить»
  (официальный установщик), «не выполнен вход» → «Войти», «всё готово ✓»;
- **живёт у часов**, запускается с системой, сайт будит её ссылкой `amplifie://`,
  обновляется сама и **не посреди ответа**;
- **подпись**: Mac — обязательно (без неё не откроется), Windows — позже;
  до подписи Windows показывает «Система защитила ваш компьютер» → «Подробнее» →
  «Выполнить в любом случае».

## Почему не другое

- **Кнопка «Запустить» прямо на сайте.** Невозможно: браузер не даёт странице
  запускать программы на компьютере — иначе любая страница запускала бы что угодно.
  Ближайшее — ссылка `amplifie://`, но она будит уже поставленную программу.
- **Б. Один файл двойным щелчком** (Node, собранный в один `.exe`). Проще программы
  на пару дней, но это чёрное окно, которое нельзя закрыть: закрыл — модель
  замолчала; с системой не стартует; подпись на Mac нужна та же. Подключение без
  кода и проверка Claude у Б и В общие — разница только в оболочке, и экономия
  не стоит окна, которое человек закроет в первый же день.
- **Tauri вместо Electron, как у Buzz.** Программа легче, но мост у нас на Node —
  его пришлось бы возить рядом отдельным Node (Buzz так и делает: качает Node
  сам). Два рантайма ради веса установщика — раньше времени.
- **Опубликовать мост в npm.** Строка короче, но это аккаунт npm и публикация
  наружу под нашим именем; файл с нашего сервера делает то же без них.
- **Установка «одной строкой из интернета» в PowerShell** (`irm … | iex`).
  Windows Defender помечает её как вирус, и метка липкая — Buzz на этом обжёгся.
  Установщик Claude скачивается в файл и запускается файлом.

## Чем платим

- Electron — установщик около 100 МБ ради окна у часов;
- $99 в год за аккаунт Apple — без него на Mac программа не откроется;
- неподписанная программа на Windows пугает синим окном, пока не купим подпись;
- ещё одна вещь, которую надо выпускать: сборка, версии, обновления.

## Что нашли у других

Разобраны 11.09 по локальным копиям репозиториев (свежесть — 28.08.2026).

**Multica** — ближе всех к нам: веб-сайт, агент на машине человека.

- Главная карточка на сайте — «Скачать программу» (Electron, внутри их CLI);
  человек входит на сайт внутри программы, программа сама делает долгий ключ
  и запускает мост (`apps/desktop/src/main/daemon-manager.ts`).
- Для программистов — строка установки: `install.ps1` для Windows (без прав
  админа, в папку пользователя, со сверкой контрольной суммы), `install.sh`
  для Mac и Linux.
- Окно подключения на сайте становится зелёным само, по событию регистрации
  моста (`packages/views/runtimes/components/connect-remote-dialog.tsx`).
- Обновляется сам и перезапускается только когда нет работы
  (`server/internal/daemon/auto_update.go`, `apps/desktop/.../version-decision.ts`).
- Программа для Windows выходит **неподписанной**, для Mac — подписанной вручную.

**Buzz** — программа на Tauri, мост у них внутри программы.

- Экран настройки: «Установить» запускает официальный установщик Claude и
  показывает ход; «Войти» запускает вход Claude и каждые 2 с спрашивает
  `claude auth status`, пока не станет «вошёл»
  (`desktop/src/features/onboarding/ui/SetupStep.tsx`, `readiness/cli_probe.rs`).
- Сайт будит программу ссылкой `buzz://`; запущенная программа принимает
  ссылку, а не открывается второй раз (`desktop/src-tauri/src/deep_link.rs`).
- Mac — подписан и заверен Apple; Windows — неподписанный установщик
  с пометкой «alpha».

**Paperclip** — только терминал, Windows не поддерживает; ценное — подключение
и проверка.

- Подключение без кода: команда открывает страницу, человек жмёт «Разрешить»,
  команда ждёт и получает ключ (`cli/src/client/board-auth.ts`, `ui/src/pages/CliAuth.tsx`).
- Честная проверка Claude: короткий вопрос «ответь hello». Не ответил — понятная
  причина и ссылка на вход; «установлен» и «вошёл» — две разные проверки
  (`packages/adapters/claude-local/src/server/test.ts`).

**Грабли, на которые наступили все трое:**

- программа, запущенная ярлыком, не видит того, что видит терминал: Claude
  «пропадает», хотя стоит. Все ищут его ещё и в известных папках
  (`%APPDATA%\npm`, `~/.local/bin`, `/opt/homebrew/bin`) и спрашивают оболочку входа;
- на Windows `claude` бывает обёрткой `.cmd` — её запускают через `cmd.exe`,
  а не напрямую;
- заданный на машине ключ Anthropic молча тратится вместо подписки —
  Paperclip об этом предупреждает;
- «ключ истёк» — только явный ответ 401, а не любой сбой сети, иначе моргнула
  сеть — и человека заставляют входить заново (Multica).
