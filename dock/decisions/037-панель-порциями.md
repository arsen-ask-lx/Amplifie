# Р-037. Панель растёт порциями

| | |
|---|---|
| **Статус** | ✅ принято 2026-09-11 |
| **Почему сейчас** | 100 проектов с 10–100 чатами превращают текущий полный ответ и тысячи DOM-строк в постоянную цену каждого обновления. |
| **Связано** | [Р-011](011-навигация-при-росте.md) · [Р-032](032-проекты.md) |

## Решение

У панели **одна полоса прокрутки**. Внутреннего scroll у проекта нет.

Первый ответ панели содержит только видимые проекты с их счётчиками и первую
порцию «Недавних». Проект раскрывается по намерению человека и получает первые
10 видимых ему чатов. После них стоит строка **«Показать ещё»**: она загружает
следующую порцию из 25. У «Недавних» следующая порция подгружается, когда низ
этой секции входит в общий scroll-контейнер.

Все проекты, кроме проекта открытого разговора, стартуют свёрнутыми. Иначе
первый экран ста проектов породил бы сто запросов и тысячу строк ещё до
действия человека.

Страницы идут курсором по серверному порядку, не смещением. В порядке есть
закрепление, последняя активность и стабильный идентификатор; новый разговор не
сдвигает уже показанную «страницу 2» и не создаёт дубль на клиенте. Сервер
возвращает только видимые человеку чаты; `total` и счётчики также считаются
только по видимым — закрытые чаты не становятся боковым каналом.

## Почему не несколько скроллов

Вложенная прокрутка ловит колесо непредсказуемо: человек над проектом двигает
не всю панель, а маленькое окно внутри неё. Это хуже становится с тачпадом и
клавиатурой. Одно направление должно иметь одного владельца.

## Почему не страницы панели

Номер страницы прячет проект или чат именно в тот момент, когда человек идёт
его искать. Discord позволяет свернуть категорию и оставить видимыми
непрочитанные каналы, а Slack управляет видимым списком разделами и фильтрами.
Мы берём тот же принцип без лишних личных папок: скрываем не данные, а ещё не
нужные строки.

## Цена

- переход с полного `/v1/conversations` на краткий снимок панели и две
  курсорные двери; это изменение контракта, поэтому оно описано в OpenSpec;
- когда проект быстро меняется, следующая страница может получить новый
  порядок. Клиент объединяет страницы по идентификатору, серверный снимок при
  следующем событии остаётся источником правды;
- виртуализация DOM сейчас не вводится: при порциях максимум десятки строк.
  Её порог — замер, на котором одна загруженная порция тормозит прокрутку.

## Источники

Проверялось 2026-09-11.

- [Discord: Channel Categories](https://support.discord.com/hc/en-us/articles/115001580171-Channel-Categories-101) — свёрнутая категория показывает каналы с непрочитанным, а не держит всё раскрытым.
